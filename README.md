# A11y-cypress-axe


#### Install node and nvm
    https://nodejs.org/en/download/

#### Install Cypress and Cypress Axe
    npm init -y
    npm i -D cypress@4.8.0 cypress-axe@0.8.1

### Open Cypress
    npx cypress open

### Install Applitools
    npm i -D @applitools/eyes-cypress@3.13.4
    npx eyes-setup

### Export Applitools
    export APPLITOOLS_API_KEY=
